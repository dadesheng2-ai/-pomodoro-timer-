ポモドーロタイマー PWA

このフォルダーを静的サイトとしてHTTPSで公開してください。index.html を含む全ファイルを、同じディレクトリ構成で配置します。

公開後のiPhone設定
1. iPhoneのSafariで公開URLを開く
2. 共有ボタンをタップ
3. 「ホーム画面に追加」を選ぶ
4. 追加したPomodoroアイコンから起動する

注意
- file:// で開いたHTMLやHTTPのURLでは、PWAとして追加できません。HTTPSが必要です。
- 初回起動時はオンライン接続が必要です。キャッシュ後はオフラインでもアプリ画面を開けます。
- タイマーはアプリを閉じたりiPhoneをロックした状態で正確に動き続ける保証はありません。iOSのバックグラウンド制限によります。
- 記録と設定はブラウザー内に保存され、端末間では同期されません。
